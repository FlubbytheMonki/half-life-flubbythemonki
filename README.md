I recently started working on starbie, a physical, sort of tomogotchi thats a star. It responds to your actions with controls on the board itself, designed in Kicad. 
This is really cool. Theres a menu that you can control with the buttons on the side and everything lays on the design that we made in Kicad. 
I feel like KiCad opened a whole new aspect of embedded programming that I never knew about. I thought pcbs were really hard to do but turns out that that isnt entirely the case.
